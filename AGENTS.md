# Project guidance

Author: Komorebi P.

This public repository deploys the Do Nothing Foundation browser runtime and Windows application. Keep BiB's Go and Python source, canonical development website, original archive, and internal records in the private development workspace. Do not put user saves, personal information, payment content, source maps, or development files in a public runtime ZIP.

Preserve the existing CRT story, crack route, ending, original media, signal effects, controls, and user saves. Use procedural rendering for new visuals. Pages serves the browser edition and pre-rendered gallery. Document what was actually verified. Native Windows execution requires a Windows test.

Follow docs/GITHUB_SETUP.md for staging and deployment. Make changes on branches and open pull requests unless the user authorizes direct main changes.
