# Do Nothing Foundation

Author: Komorebi P.

BiB is an interactive CRT experience. The project site opens the browser edition and offers the Windows x64 application in its menu.

The browser edition includes a touch-accessible intro skip and signal controls for motion, visual intensity, and audio. Story resets preserve those preferences.

[Open BiB on GitHub Pages](https://komorebip.github.io/donothingfoundation/)

This public repository contains Pages deployment files. The Go launcher, Python Signal Studio, and original development archive are kept private. The browser edition serves the runtime assets required to play BiB. The two Signal Studio clips are pre-rendered examples.

See [GitHub setup](docs/GITHUB_SETUP.md) for deployment and [Actions](https://github.com/KomorebiP/donothingfoundation/actions) for the current deployment status.
